# Intune

Device management through Microsoft Graph, scripts deployed to devices, and Autopilot.

## Subfolders

- [Admin](Admin/): reports and bulk actions run from your PC
- [On-Device](On-Device/): fixes deployed to devices through Intune or RMM
- [Autopilot](Autopilot/): hardware hashes and the update package for pre-provisioning
